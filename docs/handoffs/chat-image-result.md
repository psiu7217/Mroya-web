# Переход от генерации к готовому изображению

В мобильной Мрое пользователь заметил промежуточную надпись «Изображение создано». Она появлялась после анимации и оставалась отдельной плашкой под готовым ответом. В вебе после [PR #99](https://github.com/psiu7217/Mroya-web/pull/99) есть похожий переход. При успехе инструмента карточка переходит в `finishing` и показывает «Изображение готово», а после появления URL уходит до загрузки превью. Перенести непрерывный переход из [мобильного PR #35](https://github.com/psiu7217/Mroya-mobile/pull/35).

## Критерии приёмки

- Пока Мроя готовит ответ, показываются три точки. При запуске `generate_image` их сменяет существующая анимированная заглушка.
- После успешного события инструмента та же заглушка остаётся на месте. Сохранить анимацию и оценочный процент, пока приходят финальный ответ и байты защищённого превью.
- Заглушку сразу заменяет готовый ответ с изображением. Убрать промежуточную надпись и отдельную плашку успешного создания под картинкой. Текст, который сама Мроя прислала в ответе, показывается как обычно.
- При ошибке генерации, прерывании ответа или ошибке загрузки картинки анимация завершается, пользователь получает штатное сообщение и доступное действие повторной попытки. Сохранить уменьшенное движение и действующий просмотр изображения.
- Проверить с раздельными задержками между успехом инструмента и финальным SSE-ответом, затем между появлением Markdown с URL и событием загрузки изображения. В обоих промежутках видна заглушка. В готовом ответе видна картинка. Промежуточной и финальной плашек успеха нет. Проверить узкий экран и обычный текстовый ответ.

Исходные компоненты — `ChatWorkspace.tsx`, `ImageGenerationCard.tsx`, `AssistantMarkdown.tsx` и `src/utils/imageGeneration.ts`. Использовать действующие SSE-события и защищённую загрузку изображений.
