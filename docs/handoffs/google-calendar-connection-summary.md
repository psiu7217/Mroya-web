# Короткий статус Google Calendar

Упростить обзор Google Calendar в настройках. [Мобильный PR №60](https://github.com/psiu7217/Mroya-mobile/pull/60).

- Без подключённого аккаунта показывать в основном блоке одну кнопку «Подключить» с существующим OAuth-переходом. При необходимости повторного подключения показать действие «Подключить заново».
- Для активного аккаунта показать «Подключено» и включена ли автосинхронизация. Добавлять короткий статус, когда синхронизация идёт, прошла частично или требует действия. Для нескольких аккаунтов оставить имя аккаунта для различения.
- Убрать из обзора дату и время последней синхронизации, количество импортируемых календарей, сводку экспорта, очередей, ошибок и конфликтов. Сохранить отдельные настройки выбора календарей, кнопку «Синхронизировать» и подтверждение отключения аккаунта.
- Сохранить двустороннюю синхронизацию и ссылку из основного календаря к настройкам Google Calendar.

Проверить `src/components/ConnectionsSettingsView.tsx` и переводы `connections.json`. Сверить состояния с подключённым аккаунтом, без аккаунта и при частичной синхронизации. Проверить выбор календарей, ручную синхронизацию, отключение и возврат в календарь на русском и английском.

Пауза анализа событий описана отдельно. [Web PR №104](https://github.com/psiu7217/Mroya-web/pull/104).
