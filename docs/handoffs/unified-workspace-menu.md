# Единое боковое меню в Mroya Web

Перенести поведение основного меню из мобильных [PR №46](https://github.com/psiu7217/Mroya-mobile/pull/46) и [PR №47](https://github.com/psiu7217/Mroya-mobile/pull/47). В мобильной версии первый PR исправил переход через чат из «Файлов», а второй распространил одну кнопку и одно действие на основные разделы.

На текущем Web уже есть общий `Sidebar` и оболочка `WorkspaceSurface`. В `WorkspaceView` передаются отдельные обработчики по разделам, а кнопки отрисовываются в нескольких заголовках. В «Файлах» используется обработчик, названный для подключений. Сверить поведение опубликованной ветки и использовать существующее состояние меню.

## Задача

- Использовать единый компонент кнопки в заголовках основных разделов и один обработчик открытия мобильного меню.
- Открывать меню поверх текущего раздела. Открытие или закрытие меню сохраняет выбранную страницу, чат, фильтры, поиск и прокрутку. Навигация происходит при выборе пункта.
- Повторный выбор активного раздела закрывает меню на той же странице. Активный пункт подсвечивается. В карточках и вложенных экранах стрелка выполняет обычный возврат.
- Сохранить существующий жест и сворачивание боковой панели на десктопе. Общая кнопка доступна с клавиатуры и имеет локализованное название. При закрытии вернуть фокус в область, из которой открыли меню.

## Проверка

На узком экране открыть меню из чата, «Файлов», календаря, заметок, памяти, карты памяти, подключений, настроек и AI-задач, где они представлены самостоятельными страницами. Проверить закрытие через подложку и Escape, повторный выбор текущего пункта и переход в другой раздел. В «Файлах» повторить с активным поиском и прокруткой, в календаре с выбранным месяцем. На десктопе проверить разворачивание свёрнутой панели.

Сетка и визуал «Файлов» описаны в [Web PR №101](https://github.com/psiu7217/Mroya-web/pull/101).
